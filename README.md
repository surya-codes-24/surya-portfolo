# S. Surya — Portfolio

A responsive embedded-engineering portfolio built with plain HTML, CSS and JavaScript.

## Structure

```text
surya-portfolio/
├── index.html
├── style.css
├── script.js
├── assets/
│   ├── profile.jpg
│   └── Surya_Resume.pdf
└── README.md
```

## Run locally

Just open `index.html` in a browser.

For a smoother local preview, use VS Code + Live Server.

## GitHub / Vercel

1. Create a GitHub repository.
2. Upload all files and folders.
3. Keep `assets/profile.jpg` and `assets/Surya_Resume.pdf` in the same paths.
4. Import the GitHub repository into Vercel.
5. Deploy.

The GitHub section automatically checks `surya-codes-24` for public repositories using the GitHub REST API.
